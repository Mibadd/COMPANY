# Website Company Profile (React + TypeScript + Vite + Tailwind)

Proyek website *company profile* modern dan responsif.

## 🚀 Teknologi

* Vite
* React 19
* TypeScript
* Tailwind CSS v4
* Swiper.js (untuk carousel)
* AOS (untuk animasi scroll)

## 🛠️ Menjalankan Proyek

1.  **Clone repositori:**
    ```bash
    git clone [https://github.com/USERNAME_ANDA/NAMA_REPOSITORI_ANDA.git](https://github.com/USERNAME_ANDA/NAMA_REPOSITORI_ANDA.git)
    cd NAMA_REPOSITORI_ANDA
    ```

2.  **Install dependensi:**
    ```bash
    npm install
    ```

3.  **Jalankan server pengembangan:**
    ```bash
    npm run dev
    ```
    Buka `http://localhost:5173` (atau port yang tertera) di browser Anda.

4.  **Build untuk Produksi:**
    ```bash
    npm run build
    ```
    Hasilnya akan ada di folder `dist`.
